# Invitation de mariage

## 1. Ouvrir le projet
Ouvre le dossier dans VS Code.

## 2. Personnaliser
Dans `index.html`, remplace :
- `Aouatif`
- `Votre Prénom`
- la date
- le lieu
- les horaires

Dans `script.js`, modifie aussi `weddingDate`.

## 3. Ajouter la musique
Place ton fichier MP3 dans :
`music/wedding.mp3`

## 4. Ajouter les photos
Place tes photos dans `images/` puis utilise par exemple :
`<img src="images/couple.jpg" alt="Notre photo">`

## 5. Tester
Ouvre `index.html` avec Live Server dans VS Code.

## 6. Mettre gratuitement en ligne avec GitHub Pages
1. Crée un compte GitHub.
2. Crée un nouveau repository, par exemple `invitation-mariage`.
3. Envoie les fichiers du projet dans le repository.
4. Va dans Settings → Pages.
5. Choisis la branche `main` et le dossier `/root`.
6. Enregistre.
7. GitHub donnera une adresse publique de type :
`https://TON-PSEUDO.github.io/invitation-mariage/`

Important : pour la musique, les photos et les autres fichiers, vérifie que leurs chemins sont relatifs au projet.
